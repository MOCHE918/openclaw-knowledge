# 彩票预测方法库（离线可用，无需脚本）

## 一、梅花易数·时间起卦法（3D + 双色球）

### 起卦步骤
1. **取当前时间**：年(Y)、月(M)、日(D)、时(H)（北京时间/AST）
2. **计算各数**：
   - 年数 = (Y - 4) % 12 + 1（地支序数）
   - 月数 = (M + 1) % 12 + 1（月地支序数）
   - 日数 = D（直接取日数）
   - 时数 = floor((H + 1) / 2) % 12 + 1（时辰地支序数）
     - 子23-1, 丑1-3, 寅3-5, 卯5-7, 辰7-9, 巳9-11
     - 午11-13, 未13-15, 申15-17, 酉17-19, 戌19-21, 亥21-23
3. **起卦**：
   - 上卦数 = (年+月+日) % 8（余0则取8）
   - 下卦数 = (上卦数+时数) % 8（余0则取8）
   - 动爻 = (年+月+日+时) % 6（余0则取6）
4. **先天八卦数**：1乾、2兑、3离、4震、5巽、6坎、7艮、8坤
5. **生成随机种子**：seed = SHA256("上卦|下卦|动爻|年|月|日|时") 的前32位
6. **用LCG随机数洗牌取号**：
   - LCG: s = (s * 1103515245 + 12345) & 0x7fffffff
   - 多次调用直到取得所需数量的号码

### 3D号码生成
- 池子：0-9（共10个）
- 取3个，排序后输出
- 判断类型：全同=豹子，2同=组三，全异=组六

### 双色球号码生成
- 红球池：1-33，取6个（无重复）
- 蓝球池：1-16，取1个
- 蓝球用不同的种子偏移：seed ^ 0xB10E

### 卦象解读
- **本卦**：用上卦数、下卦数查先天八卦名 → 六十四卦名
- **互卦**：六爻中第2、3、4爻（下互）和第3、4、5爻（上互）
- **变卦**：动爻位阴阳翻转后的新卦
- 爻排列：从下到上（初爻→上爻）
- 八卦爻：乾111 兑110 离101 震100 巽011 坎010 艮001 坤000

## 二、福彩3D统计分析法

### 数据源
- cwl.gov.cn API：findDrawNotice?name=3d&pageNo=1&pageSize=60
- 需在页面上下文内调用（需要Referer和同域cookie）

### 三步筛选法

#### 第一步：形态判断
- 检查最近组三连续出现次数
- 组三连1期 → 下期组六概率 = 1-30%=70%，组三=30%
- 组三连2期 → 组六55%，组三45%
- 组三连3+期 → 组六72%，组三28%
- 50期历史中组三占比约30%

#### 第二步：和值定区间
- 计算最近50期和值波动平均值（约±6）
- 上期和值 ± (平均波动+1) 为推荐区间
- 取历史热门的和值（出现频率≥2次的）

#### 第三步：热冷配号
- **热号**（最近50期出现最多的）
- **近10期热度**用于给组合评分
- 从热门号码区取7个作为候选池
- 组六：C(7,3)=35种组合，按近10期热度评分排序，过滤和值，取前10
- 组三：候选5个号码，两两配对（AAB），同样过滤和值，取前6
- 胆码：前3热+后2温 = 5个核心号

## 三、双色球统计分析法（12法完整版）

### 数据源
- 同API：name=ssq&pageNo=1&pageSize=50

### 12维分析方法
1. **频率统计**：短(10期)、中(50期)、长(历史)三期分离 -> 识别过热/过冷
   - 理论概率=6/33≈18.18%，频率>1.5倍=过热，<0.5倍=过冷
2. **遗漏值分析**：当前遗漏=自上次出现后的期数
   - 冷号界值=平均遗漏×1.5，热号界值=平均遗漏×0.5
3. **和值分析**：理论均值102，黄金带75-110（历史高频区间）
   - 正态分布N(102, 13.5²)：68%落在88-116，95%落在75-129
4. **AC值分析（号码离散度）**：所有两两差值的种类数
   - C(6,2)=15种差，推荐7-9（中等离散）
5. **跨度分析**：max-min
   - 推荐20-28（覆盖面广，分布均衡）
6. **奇偶比**：3:3(35%)>4:2/2:4(各25%)，避免0:6/6:0
7. **大小比**：01-16小，17-33大，3:3最常见
8. **区间分析**：一区01-11、二区12-22、三区23-33，2:2:2最优
9. **连号分析**：约70%含连号，2连号占60%，每注建议含1-2组
10. **012路分析**：除3余0/1/2，推荐2:2:2或1:2:3
11. **蓝球分析**：16选1，遗漏>10期优先关注
12. **综合评分模型**：对每注进行和值(25%)+AC值(15%)+跨度(15%)+奇偶(12%)+连号(10%)+012路(10%)+区间(8%)评分

### 推荐生成策略
- 3热+2温+1冷配比，结合随机变异
- 蓝球：热号+高遗漏混合
- 按综合评分排序输出8注
- 去重机制（哈希集合）
