### 关键发现
- **Tsinghua pypi镜像的2021版包不全** — MKL/intel-openmp/tbb都跑到官方PyPI上找（出国慢）
- **解决办法：** 从清华镜像html索引爬出具体wheel URL → 直接下载 → pip install --no-index --no-deps 安装
- **PIP_INDEX_URL 陷阱：** 设了清华索引后，装新包时可能把CUDA torch换成CPU版（因为依赖冲突）
- **pip cache 大文件（>2GB）可能损坏** — 中断的pip install导致cache metadata损坏，用 `--no-cache-dir` 可绕过
- **PowerShell的curl是Invoke-WebRequest别名** — 需用 `New-Object System.Net.WebClient` 下载大文件
