## 下午：SearXNG 搜索通道搭建（12:30~13:10）

### 背景
- 用户没有信用卡，无法注册 Brave Search API / Bing Search API
- 讨论后决定走自建搜索路线——在阿里云VPS上部署 SearXNG

### VPS环境
- Ubuntu 24.04 LTS | 内存 894MB | 可用 353MB | 磁盘 21GB空余
- Docker 29.1.3（刚装上）
- SSH密钥路径：`D:\Portable_V1.2.2\data\UserProfile\.ssh\openclaw_agent_key`（D盘exFAT格式不支持icacls，需复制到C盘用）
- 密钥正确权限修复：`icacls "C:\Users\Administrator\.ssh\openclaw_agent_key" /grant "${env:USERNAME}:R" /inheritance:r`

### 部署步骤
1. `apt-get install docker.io`
2. `docker run -d --name searxng -p 8080:8080 searxng/searxng`
3. 配置JSON API + 禁用限流器
4. 启用百度引擎（默认disabled: true）
5. 设置必应使用 cn.bing.com
6. settings.yml 通过 `-v /opt/searxng/settings.yml:/etc/searxng/settings.yml:ro` 挂载

### 当前搜索能力
| 引擎 | 状态 | 说明 |
|------|------|------|
| Brave | ✅ | 英文搜索主力 |
| Baidu | ✅ | 中文搜索，刚启用 |
| Bing (cn.bing.com) | ✅ | 中文搜索辅助 |
| Wikipedia | ✅ | 内置 |
| Google | ❌ CAPTCHA | VPS IP被封 |
| DuckDuckGo | ❌ CAPTCHA | VPS IP被封 |

### 搜索脚本
- `_searx_search.py` — 本地搜索脚本（通过SSH→VPS→SearXNG）
- 每次搜索同时查3个引擎，结果聚合

### 技术笔记
- PowerShell的`<<` heredoc在和SSH命令结合时完全不能用
- `&`符号在PowerShell中是命令分隔符，URL中必须加引号转义
- D盘exFAT不支持ACL → SSH密钥必须拷贝到C盘并修正权限
- SearXNG的settings.yml用`use_default_settings: true` + engines override方式最干净
- Docker镜像约 200MB，运行时占内存约 100-150MB
