### 🔧 关机问题排查与解决（完整方案）
- **问题：双击桌面 OpenClaw 快捷方式 → OpenClawManager.exe 启动 → 调用 shutdown.exe（原因码 0x800000ff）→ 系统无提示关机**
- 已确认是 OpenClawManager.exe v1.0.0 的 BUG，启动时自动触发系统重启
- 系统日志显示多天来每天都有同样模式的无提示关机
- 尝试方案1（已废弃）：用 C# 编译 `MoChe.exe` 启动器，用户拒绝（"不要更改启动程序"）
- **最终方案：创建傀儡 shutdown.exe（C#, NET Framework 4.8, 3.5KB）**，放在 `E:\Portable_V1.2.2\` 目录下
  - 原理：Windows 优先查找当前目录的 .exe，Manager.exe 调用 shutdown() 时会优先命中傀儡文件
  - 代码：Console.WriteLine("Intercepted") + Environment.Exit(0)
  - 完全可逆：删除 `E:\Portable_V1.2.2\shutdown.exe` 即可恢复
- Manager 快捷方式仍保留，用户双击后会自动重启，重启后能正常运行
