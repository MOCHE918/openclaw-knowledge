## 一、核心问题：怎么定量刻画一注彩票？

彩票不是"六个号码"这么简单。每注开奖号码背后有一整套**结构特征**。

我们把每注号码转化成13个量化维度（**示例**）：

```javascript
// 13维特征提取 — 结构展示 (示例)
function extractFeatures(combo) {
  return {
    sum:   红球总和,          // e.g. 122
    span:  最大-最小,          // e.g. 18
    odd:   奇数个数,           // e.g. 2
    even:  偶数个数,           // e.g. 4
    big:   ≥17的个数,          // e.g. 3
    small: <17的个数,          // e.g. 3
    z1:    1-11区个数,         // e.g. 1
    z2:    12-22区个数,        // e.g. 3
    z3:    23-33区个数,        // e.g. 2
    ac:    算术复杂度,          // 两两差值不重复数-5
    consec:连号对数,           // e.g. 0
    uniqueTails:不重复尾数种数, // e.g. 5
    primeCnt: 质数个数          // e.g. 2
  };
}
```

**这意味着什么？**
不再靠"感觉"说这注号码"看起来顺眼"——而是每个维度的数值都能和历史分布做精确比较。

## 三、Nyāya模式匹配：从历史中找规律

### 原理

如果历史上某一段时期的走势特征和当前非常相似，那么那段时期之后的开奖结果，就可能是当前期的**参考样本**。

```
步骤1：取最近一个固定窗口长度内的开奖
       计算其多个关键特征的均值
       → 构成「当前画像向量」

步骤2：滑窗遍历全部历史，每滑动一期计算一个「历史画像向量」
       → 全部历史窗口画像

步骤3：计算当前画像与每个历史画像的相似度
       → 选出相似度最高的Top K个窗口

步骤4：对每个高相似窗口，取它下一期的开奖号码
       → 按相似度加权评分

步骤5：按得分排序取Top N作为候选红球池
       → 进入下一阶段全组合搜索
```

### 窗口长度为什么选这个值？

这是个关键参数。我们测试了多组取值（**示例**：10/20/30/50/100期），通过历史回测比较不同窗口的匹配精度和稳定性。最终选定的值在**匹配敏锐度和抗噪声能力**之间达到了最佳平衡：

- 窗口太小 → 容易被偶然波动误导
- 窗口太大 → 近期趋势被大面积历史淹没，响应迟钝

选定值是一个经过多组对比回测后的折中方案。

### 核心逻辑（伪代码）

```javascript
function selectCandidates(historyData, topN) {
  // 当前画像 = 最近W期的特征均值
  const currentProfile = buildProfile(historyData, -W);
  
  // 滑窗遍历：计算每个历史窗口的相似度
  const similarities = [];
  for (let ws = 0; ws < historyData.length - W - 1; ws++) {
    const hp = buildProfile(historyData, ws, W);
    similarities.push({ ws, sim: cosineSimilarity(currentProfile, hp) });
  }
  
  // 选Top K个最相似窗口，取下一期号码加权聚合
  const topK = similarities.sort((a,b) => b.sim - a.sim).slice(0, K);
  const ballScores = aggregateWeighted(topK, historyData);
  return ballScores.slice(0, topN);
}
```

### 为什么叫Nyāya？

Nyāya是古印度因明学的推理范式。核心思想：**通过已知案例推理未知结论**——和我们"用历史相似窗口推测当期"的逻辑完全一致。取名不是玄学包装，是这个方法本质上就是因明推理的数据实现。

## 四、全组合搜索 + 混合评分

拿到Top N候选红球后，**穷举全部C(N,6)种组合**逐一评估。

### 评分公式（概述）

```
混合评分 = Z²(特征贴合度) × 权重α + 球热度排名 × 权重β
```

- **Z²**：组合的多维特征与近期画像的偏离度，越小越"典型"
- **球热度排名**：近期每个球的出现频次排名
- **α、β**：通过回测调整的权重比例

### 评分流程

```
候选池(N个球)
  ↓
穷举所有6球组合（C(N,6)种）
  ↓
每个组合计算特征向量
  ↓
Z²评分 + 热度评分 → 加权排序
  ↓
Top1主推 + Top10覆盖方案
```

### 蓝球：多方法投票融合

| 方法 | 原理 | 权重 |
|------|------|------|
| 频率法 | 历史出现频次统计 | 较高 |
| 马尔可夫链 | 上期蓝球→本期转移概率 | 中 |
| 尾数马尔可夫 | 尾数级别的转移模式 | 中 |
| 冷号捕捉 | 概率偏离+冷号加权 | 中 |

多方法投票加权，取Top 3推荐。

## 七、我们的方法论特点

**1. 不依赖黑盒模型**
没有神经网络、没有深度学习——所有计算可解释、可复现、可审计。

**2. 多维度交叉验证**
一个模型的结果不单独采信，需要多维度交叉检查：特征偏离、频率统计、模式匹配、随机性检验。

**3. 工具链工程化**
不是零散脚本，是完整工具链：数据采集→存储→分析→预测→报告，全流程自动化。

**4. 持续迭代**
每个版本都有明确的实验记录：为什么加这个特征、为什么调整参数、回测结果如何。不做"一拍脑袋"的改动。
