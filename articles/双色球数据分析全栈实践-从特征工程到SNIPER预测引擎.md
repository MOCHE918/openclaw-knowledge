# 双色球数据分析全栈实践：从特征工程到SNIPER预测引擎

## 前言

彩票数据分析是个争议性话题——有人说是玄学，有人说纯概率。我选择第三条路：**用数据说话**。

双色球（SSQ）作为国内彩市头牌，其红球33选6、蓝球16选1的规则看似简单，但背后有大量可挖掘的统计规律。这半年来我做了一套完整的数据分析系统，把工程思维和数据科学的方法都怼进去了。

## 数据采集：从2013到2026

数据是一切的基础。VPS上每天跑爬虫，维护了从**2013年1月到2026年7月**的完整历史数据：

```
数据总量：2035期
时间跨度：13年
数据字段：期号、日期、红球1-6、蓝球
文件格式：JSON（ssq_history.json，~471KB）
```

还顺带维护了大乐透（DLT）、福彩3D（FC3D）、排列三（PLS）的数据。

这些数据存储在阿里云香港VPS（2核1G/30GB磁盘）上，Node.js爬虫每期自动更新。

## 特征工程：13维画像系统

每注双色球开奖号码，我抽取出 **13个特征** 来刻画它的"样子"：

```javascript
特征维度：
  sum:        和值（红球总和）
  span:       跨度（最大-最小）
  odd/even:   奇偶比
  big/small:  大小比（≥17为大）
  z1/z2/z3:   三区间分布（1-11, 12-22, 23-33）
  ac:         AC值（算术复杂度）
  consec:     连号数
  uniqueTails:尾数种数
  primeCnt:   质数个数
```

通过这13个维度，每期开奖号码都转化成了一个**数值画像向量**，可以用统计方法分析其分布规律。

比如历史均值和标准差：

| 特征 | 均值 | 标准差 | 典型范围 |
|------|------|--------|----------|
| 和值 | 102.3 | ~21 | 81~123 |
| 跨度 | 24.8 | ~6 | 19~31 |
| 奇偶 | 3:3 | ~1.2 | 2:4 ~ 4:2 |
| 大小 | 3:3 | ~1.3 | 2:4 ~ 4:2 |
| 三区间 | (2,2,2) | ~0.8 | 各类分布 |
| AC值 | 7.9 | ~2.1 | 6~10 |
| 连号 | 0.8 | ~0.8 | 0~2 |
| 尾数 | 5.2 | ~0.9 | 4~6 |
| 质数 | 1.7 | ~1.1 | 1~3 |

## 核心算法：Nyāya 模式匹配过滤器

这是整个系统的**灵魂算法**，灵感来自古印度因明学（Nyāya）的推理范式。

**原理：** 历史开奖中，相似的模式会重复出现。如果某段历史区间（比如1~99期）的特征曲线和当前期接近，那这段区间的下一期号码就值得重点参考。

**具体实现：**

1. 取最近30期为"当前画像"
2. 遍历整个历史，找到特征曲线最相似的20个"历史窗口"
3. 对每个相似窗口，获取其**下一期**的开奖号码
4. 按相似度加权评分，取Top18作为候选池

```
当前画像 ← 最近30期特征均值
历史窗口 → 计算余弦相似度 → 选Top20
         ↓
每个窗口的下一期号码 → 加权评分
         ↓
         Top18候选红球
```

为什么是1~99期作为固定池？实验发现这个窗口效果最好，大于99期反而引入噪声。

## 全组合搜索：C(18,6) = 18,564注

拿到18个候选红球后，不按排名简单取前6——而是**遍历所有C(18,6) = 18,564种组合**，用混合评分函数全面评估。

**混合评分 = Z²(特征贴合度) × 0.5 + 球热度排名 × 0.5**

- **Z²**：组合的13维特征向量与最近100期均值分布的偏离度，越小越"典型"
- **球热度**：最近100期内每个球的出现频率排名，越热越好

两者各占50%，最终得分最低的为首推。

## 蓝球预测：四法投票融合

蓝球16选1，单独设计了4种预测方法进行投票融合：

| 方法 | 原理 | 权重 |
|------|------|------|
| **频率法** | 统计历史出现频次 | 1.2 |
| **马尔可夫链** | 上一期蓝球 → 下一期的转移概率 | 1.0 |
| **尾数马尔可夫** | 尾数级别的转移模式 | 0.8 |
| **冷号捕捉** | 概率偏离 + 冷号加权 | 0.8 |

四种方法的结果按权重投票，取Top3为推荐蓝球。

## 完整工具链

除了预测引擎，还构建了以下配套工具：

### 1. SSQ Toolkit — 分析方法库（11模块）

这是最重的工程成果，包含：

- **模块1-2：** 基础统计 + 频率分析 + Genest校正卡方检验
- **模块3：** 遗漏值概率模型（计算长期未出号码的概率）
- **模块4：** 均值回归检测
- **模块5：** 游程检验（Wald-Wolfowitz Runs Test）
- **模块6：** 马尔可夫转移矩阵 + 共现分析
- **模块7：** Lotterycodex 4分区模板匹配
- **模块8：** 随机性综合诊断（8项统计检验打包）
- **模块9：** **物理孪生模型** — 基于摇奖机物理参数（Ryo-Catteau Myosotis型号）的upSens + power校准
- **模块10：** 预测引擎（纯频率法基线）
- **模块11：** 完整报告生成

### 2. Auto Pipeline — 自动化管线

一键运行管线：
```
数据检查 → 全量分析 → Nyāya更新 → 备选推荐 → 完整报告输出
```

### 3. Purchase Optimizer — 购票优化器

给定N注预算，自动选出最优组合覆盖方案：
```
阶段1：过滤层 → Nyāya池 + 混合评分 → Top K候选
阶段2：多样化层 → 贪婪选择 + 特征空间覆盖最大化
```
