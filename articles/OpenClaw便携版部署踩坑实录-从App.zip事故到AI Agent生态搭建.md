# 从零开始的AI Agent之旅：OpenClaw便携版部署踩坑实录

## 前言

接触OpenClaw两个月了，作为一个传统工程/贸易行业出身、刚跨入AI圈的新手，这中间踩的坑、掉的泪、学到的东西，值得记录下来。

这篇文章写给所有想入坑AI Agent但不知道从哪下手的伙伴。

## 第一坑：App.zip，那个差点让我崩溃的文件

OpenClaw便携版的核心启动文件是 `app.zip`（约157MB）。

**别手贱删它。**

我第一次清理磁盘时把它列进了"可以删的安装包"清单里，一脚下去，移到了外接电脑上。结果启动时报错"应用文件缺失"，便携版彻底罢工。

修复很简单——找另一台电脑上的备份拷贝回来。但教训深刻：

> **app.zip不是安装包，是便携版的灵魂。没有它，一切免谈。**

后来我在 MEMORY.md 里用红色大字写上了警告，生怕自己再犯同样的错。

## 第二坑：磁盘空间，便携版的命门

OpenClaw跑在U盘上（我的D盘只有14.6GB），这意味着：

- Python包（numpy、PIL、torch等一堆）吃空间
- pip缓存吃掉3GB
- 生图模型完全装不下
- 文档、教程视频、说明书都在抢地盘

**解决方案：**
1. pip缓存迁移到U盘备份（释放3GB）
2. 教程视频、安装说明等运行不需要的文件挪走
3. PyTorch这类大件暂时不装完整版

但说实话，硬件限制是硬伤。16GB DDR4内存 + 集显 + 小容量U盘，跑SD生图基本没戏。认清硬件边界也是一种进步。

## 第三坑：会话压缩 = 记忆丢失

用AI Agent最大的坑：**会话一旦被压缩，之前聊了什么全都不知道。**

我前三天关于变现方案的讨论全丢了——Fiverr的Gig文案、Freelancer的投标模板、GitHub凭证文件……全碎在磁盘的零字节空文件里。

**血的教训：**

> **所有重要的对话内容，必须在发生时实时写入文件。不能依赖AI的会话缓存。**

我用的是 `D:\opencaw记忆录\` 目录，每次有新的安装、决策、重要讨论，立刻追加到当天的日志文件里。

## 第四坑：变现路上的清醒

刚开始接触AI时，脑子里全是"怎么赚钱"：

- Fiverr开了4个Gig（数据爬取、数据分析、Excel处理、文档生成）
- Freelancer.com搭了完整Profile，连投标模板都写好了
- VPS上部署了Freelancer监控脚本，每30分钟扫一次

然后呢？**一个订单都没有。**

反思后决定：
1. **Fiverr/Freelancer 放弃** — 门槛太低竞争太激烈，一个爬虫需求$10都嫌贵
2. **GitHub → 学习积累** — 做好作品集，不急于变现
3. **CSDN → 发帖记录** — 输出是最好的学习方式

**核心认知：刚入行2个月，先提升再谈变现。**

## 总结：新手入坑AI Agent的几点建议

1. **先搞清楚硬件边界** — 集显跑不了SD就是跑不了，别在这上面死磕
2. **认清楚自己在哪** — 传统行业出身、入行2个月，别急着变现，先积累
3. **一切写下来** — 会话会丢，记忆会丢，文件不会丢
4. **善用社区** — ClawHub有66,500+技能，GitHub 382K Star，CSDN有大量教程
5. **别迷信大模型** — 大模型的数据来源于网络，真假混杂，交叉验证才是硬道理
